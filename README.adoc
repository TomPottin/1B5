IUT de Blagnac - BUT Informatique - Année universitaire 2026/2027

Ce dépôt contient les travaux réalisés par notre groupe (G1B5) dans le cadre de la SAÉ 3.A.01. Le projet consiste à concevoir et développer une application e-commerce en suivant la méthodologie Agile Scrum.
